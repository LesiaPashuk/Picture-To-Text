# Picture-To-Text
[Результат](https://lesiapashuk.github.io/Picture-To-Text/pictureToText.html)

### Отчет по лабораторной работе: Конвертер изображений и анализ информации

---

#### **1. Введение**
Целью данной лабораторной работы является создание веб-приложения, которое позволяет пользователю загружать изображения, анализировать их параметры и отображать информацию о них. Приложение также предоставляет возможность загрузки нескольких изображений и отображения их данных в табличном формате.

---

#### **2. Описание задачи**
Задача заключается в следующем:
1. Реализовать возможность загрузки изображений через браузер.
2. Анализировать параметры загруженных изображений (размер, ширина, высота, глубина цвета, сжатие и т.д.).
3. Отображать информацию о каждом изображении.
4. Если загружено несколько изображений, отображать их данные в таблице.
5. Создать простой и удобный интерфейс для взаимодействия с пользователем.

---

#### **3. Реализация**

##### **3.1. Используемые технологии**
- **HTML**: для создания структуры веб-страницы.
- **CSS**: для стилизации интерфейса.
- **JavaScript**: для обработки загруженных файлов и анализа изображений.

##### **3.2. Основные компоненты программы**
1. **HTML-страница (`pictureToText.html`)**:
   - Содержит форму для загрузки изображений.
   - Предоставляет место для отображения информации о загруженных изображениях.
   - Включает таблицу для отображения данных о нескольких изображениях.

2. **JavaScript-код (`pictureToText.js`)**:
   - Обрабатывает событие загрузки файлов.
   - Анализирует параметры каждого изображения (ширина, высота, глубина цвета, сжатие и т.д.).
   - Отображает информацию о каждом изображении в зависимости от количества загруженных файлов.

3. **CSS-стили (`pictureToText.css`)**:
   - Определяют внешний вид интерфейса, включая стили для изображений и таблицы.

---

#### **4. Функциональные возможности**

##### **4.1. Загрузка изображений**
- Пользователь может загружать одно или несколько изображений через интерфейс.
- Поддерживаются форматы изображений, которые могут быть обработаны браузером (например, JPG, PNG).

##### **4.2. Анализ изображений**
- Для каждого изображения вычисляются следующие параметры:
  - Размер файла.
  - Ширина и высота.
  - Общее количество пикселей.
  - Соотношение сторон (aspect ratio).
  - Формат файла.
  - Глубина цвета (количество бит на пиксель).
  - Сжатие (отношение несжатого размера к фактическому размеру файла).

##### **4.3. Отображение информации**
- Если загружено одно изображение, информация отображается в виде текста.
- Если загружено несколько изображений, информация отображается в таблице.

##### **4.4. Интерфейс**
- Простой и интуитивно понятный интерфейс, который позволяет пользователю легко загружать файлы и просматривать информацию о них.

---

#### **5. Результаты**

##### **5.1. Загрузка изображений**
- Приложение корректно загружает изображения и отображает их на странице.

##### **5.2. Анализ изображений**
- Параметры изображений (размер, ширина, высота, глубина цвета и т.д.) вычисляются корректно.
- Сжатие изображения оценивается на основе несжатого размера (24 бита на пиксель).

##### **5.3. Отображение информации**
- Информация одного изображения отображается в текстовом формате.
- Информация о нескольких изображениях отображается в таблице.

##### **5.4. Интерфейс**
- Интерфейс интуитивно понятен и удобен для пользователя.

---

В ходе выполнения лабораторной работы было создано веб-приложение, которое позволяет загружать изображения, анализировать их параметры и отображать информацию о них. Приложение успешно обрабатывает загрузку одного или нескольких изображений, вычисляет их параметры и отображает данные в удобном формате.
